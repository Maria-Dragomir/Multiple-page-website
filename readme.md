# DOGuidance Multi-page Responsive Website

This project is a simple multi-page responsive website created for the Week 2 web development challenge.

## Project Overview

The website presents three DOGuidance pathways:

- Conscious Leader
- Canine Specialist
- ND Minds

It also includes a contact page with a simple submission form.

## Pages

- `index.htm` - Home page
- `conscious-leader.htm` - Conscious Leader pathway
- `canine-specialist.htm` - Canine Specialist pathway
- `nd-mind.htm` - ND Minds pathway
- `contact.htm` - Contact form

## Features Used

This project uses the Week 2 course concepts:

- Semantic HTML
- External CSS
- CSS variables
- Flexbox layout
- Flexbox alignment
- Pseudo-class hover effects
- Pseudo-element decorative lines
- Responsive design using media queries
- Multi-page navigation
- Contact form with labels and required fields
