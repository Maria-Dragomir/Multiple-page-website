# Multiple-page-website

## Project Overview

This project was developed as part of the Week 2 challenge, focusing on responsive web design, Flexbox layouts, CSS variables, pseudo-classes and a styled contact form.

The website was inspired by DOGuidance and structured around three key pathways:

* Conscious Leader
* Canine Specialist
* ND Minds

To keep navigation simple and responsive, I chose to use three interactive cards on the homepage rather than placing all pathways within the navigation menu. The navigation itself was simplified to Home and Contact, allowing the cards to act as the primary user journey.

## Design Approach

I intentionally kept the design minimal and clean so it could act as a flexible foundation for future development. The layout uses Flexbox throughout, CSS variables for consistent styling, hover effects for interaction, and responsive behaviour for different screen sizes.

## Learning Reflection

One of the challenges I encountered was understanding how changes made in CSS can affect multiple pages and elements simultaneously. I spent a significant amount of time exploring how styles cascade, how reusable classes work, and how to create a structure that could be expanded in future projects without unintentionally breaking existing layouts.

I used AI as a learning and support tool to help generate examples, understand code structure, and identify where individual elements should be placed. My goal was not simply to copy and paste code, but to better understand how HTML and CSS work together and to begin building reusable templates that I can continue developing independently.
